# Gene catalogs workshop

This folder is your workspace for Parts A–C of the
[gene catalogs lesson](https://microbiologyethz.github.io/Methods_in_Microbiomics/lessons/gene-catalogs/).
Open a terminal here and follow the lesson pages.

| Path | Content |
|---|---|
| `data/scaffolds/` | Assembled scaffolds (≥ 500 bp) of three metagenomes |
| `data/reads/` | Their quality-controlled reads (unpacked by `setup.sh` when the Codespace starts) |
| `check` | Run `./check a` (or `b`, `c`) to compare your results with the reference run |
| `solutions/` | Reference solutions, one script per part |

Your results go into `genes/`, `catalog/`, `alignments/` and `counts/`.
To start over, delete those folders.
